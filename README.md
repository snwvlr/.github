# .github

Community health files, profile content and shared brand assets for
[@snwvlr](https://github.com/snwvlr) and the projects under
[@Orlixys](https://github.com/Orlixys) and
[@Korppi-Mail](https://github.com/Korppi-Mail).

This repository centralises everything that should be consistent across all
public-facing projects: default templates, security policy, funding info and
the visual identity used in READMEs.

## Contents

| Path | Purpose |
|---|---|
| `profile/README.md` | Profile README rendered at `github.com/snwvlr` (organisations only) |
| `SECURITY.md` | Responsible disclosure policy for all projects |
| `CONTRIBUTING.md` | Default contribution guide for repositories without their own |
| `FUNDING.yml` | Sponsorship configuration — enables the **Sponsor** button on every repo |
| `LICENSE` | MIT license covering the contents of this repository |
| `assets/` | Brand SVGs: Korppi corvo, Orlixys, Orbit and Photon |

## How GitHub uses this repository

GitHub automatically applies the files in this repository as defaults across
**every other repository under the same account** that does not provide its
own version. That includes the security policy, contribution guide,
funding configuration and issue/PR templates.

The `profile/README.md` file is a special case: when this repository belongs
to an **organisation**, that file is what visitors see at the organisation's
URL. For personal user accounts, the profile README lives instead in a
repository named after the user.

## Brand assets

The SVGs under `assets/` are the proprietary marks of their respective
projects (Korppi Mail, Orlixys, Orbit, Photon). They are included here for
use across project READMEs. See the `LICENSE` file for the exact terms —
the MIT licence does **not** apply to the brand assets.
